How it works

Three steps, and the first one is the only one you do.

  1. 01

    Upload

    Pick a PDF from your phone or computer. It shows up in the viewer straight away, before it has even finished being read.

  2. 02

    We read it

    The text is split into short passages and indexed in memory. Scanned pages are read with OCR, so image-only PDFs work too.

  3. 03

    Ask

    Type a question. The closest passages are found and a fast model answers from them only. If the PDF does not say, it tells you so.

What an answer looks like

Questions

Straight answers.

Does it cost anything?

No. It runs on free tiers end to end, and there is no sign-up.

What if my PDF is a scan?

Pages with no selectable text are read with OCR. Very long scans are read up to the first 40 pages to stay inside free limits.

Who can see my files?

This is a shared demo with no logins, so use public or sample documents only. Files are kept in server memory and disk on a free host, and are wiped whenever it restarts.

Can it make things up?

Answers are limited to passages found in your PDF, and page references are checked against the file. When the PDF does not cover a question, you get a plain "not in the document".

Is the code open?

Yes, on GitHub. The retrieval pipeline is plain Python with FAISS and no orchestration framework.

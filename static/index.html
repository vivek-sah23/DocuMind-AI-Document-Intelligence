Features

Everything you need to learn from a document

Built for students, researchers and teams who need answers they can trust, quickly.

Your file, front and center

Every upload keeps its real file name and opens in a built-in viewer, so you can read the PDF while you chat with it.

Fast, accurate answers

Exact-match vector search finds the right passages in milliseconds, then a fast LLM writes the answer from those passages only.

Memory tips

Each answer ends with a mnemonic or shortcut, so you remember the point quickly instead of re-reading the page.

Verifiable citations

Click any citation to jump to that exact page in the preview. Page numbers come from the document, never from the model.

Many documents, one place

Keep several PDFs indexed, chat with one or search across all, and remove any file when you are done.

Works on every screen

A layout that adapts from phone to desktop, with a smooth workspace you can use anywhere.

How it works

From upload to answer in four steps

Two simple pipelines: index once, answer instantly.

  1. 1

    Upload

    Drop in a PDF. It is validated and checked so the same file is never indexed twice.

  2. 2

    Index

    Pages are split into passages and embedded with all-MiniLM-L6-v2, then stored in FAISS.

  3. 3

    Retrieve

    Your question is matched against the passages by exact cosine similarity.

  4. 4

    Answer

    A fast LLM answers only from those passages and cites the page for each claim.

Study mode

Answers that teach, not just reply

Every response is organised the same way, so you can scan it in seconds and keep it in your head.

  • Answer. The direct response, in one to three sentences.
  • Explanation. Why it is true, in plain language.
  • Key points. The facts to remember, as short bullets.
  • Memory tip. A mnemonic or pattern to recall it fast.
  • Sources. Page citations that open the PDF at the right page.

Trust

Built to be verifiable

The failure modes of document chat, designed out.

Grounded or refused

Below a similarity threshold, DocuMind says the document does not contain the answer instead of guessing.

Prompt-injection safe

Text inside a PDF is treated as data. It can never change the assistant's instructions.

Defensive uploads

Extension, magic bytes, corruption and extractable-text checks run before anything is indexed.

Secrets stay server-side

API keys live only in server environment variables, are redacted from errors, and requests are rate limited.
